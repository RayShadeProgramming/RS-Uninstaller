# RS-Uninstaller 开发周期与阶段规划

> 文档版本：v0.1（企划阶段）
> 日期：2026-10-13
> 说明：本规划只做**阶段划分**，不做细化到人天/任务的排期。每阶段给出目标、交付物与验收标准。

---

## 总体路线

```
阶段0 预研验证  →  阶段1 核心引擎  →  阶段2 安全兜底
      ↓                                    ↓
阶段5 发布交付  ←  阶段4 功能完善  ←  阶段3 图形界面
```

设计原则：**先做只读（只扫描、不删除），再做删除；先做安全兜底，再开删除能力。**

---

## 阶段 0：技术预研与只读原型

**目标**：验证"软件枚举 + 清理清单生成"的准确率，产出**不执行任何删除**的原型。

- **内容**
  - 打通三类软件来源：机器级注册表（64/32 位）、用户级注册表、UWP/Store 应用；
  - 解析卸载项字段，实现系统组件/补丁过滤；
  - 给定一款软件，生成"可能的清理清单"（文件 + 注册表），**仅展示不删除**。
- **交付物**：命令行原型（CLI）+ 一份识别准确率记录。
- **验收标准**：能正确列出本机 ≥ 95% 的常规已安装软件；清理清单对典型软件（如某浏览器）的主要目录与注册表项命中。

---

## 阶段 1：核心引擎（扫描 + 追踪）

**目标**：完成"软件扫描器"与"痕迹追踪器"，形成完整、结构化的清理清单。

- **内容**
  - 软件扫描器：多源合并、去重、过滤，输出统一软件模型；
  - 痕迹追踪器：按 `InstallLocation` / 厂商名 / 产品名，追踪文件与注册表痕迹；
  - 覆盖：安装目录、AppData/ProgramData、开始菜单快捷方式、卸载键、厂商注册表项。
- **交付物**：可复用的核心引擎库 + CLI 工具。
- **验收标准**：对典型软件输出的清理清单人工抽查准确率 ≥ 90%；误报（把不属于该软件的文件列入清单）可控。

---

## 阶段 2：安全兜底机制

**目标**：建立"出事能还原"的安全底座。**本阶段必须早于实际删除能力上线。**

- **内容**
  - 系统还原点创建；
  - 注册表备份 / 恢复（.reg 导出与回灌）;
  - 文件"隔离区"（删除前移动到隔离区，支持一键还原）；
  - 保护白名单（系统关键目录、共享运行库、.NET / VC++ 组件）。
- **交付物**：备份与还原模块 + 还原验证报告。
- **验收标准**：能完成"备份 → 删除 → 从备份 100% 还原"的闭环测试；白名单可有效拦截对系统目录的删除请求。

---

## 阶段 3：图形界面（Windows 客户端）

**目标**：产出可交互的桌面客户端，把核心能力包装成普通用户可用的产品。

- **内容**
  - 软件列表页（名称/版本/厂商/大小/安装日期，支持搜索筛选）；
  - 详情页 + 清理清单预览页（可勾选、可排除）；
  - 卸载执行页（进度、日志、结果报告）；
  - 备份/还原入口与"隔离区"管理。
- **交付物**：Windows 桌面客户端安装/绿色版。
- **验收标准**：完整跑通"选择软件 → 预览清单 → 备份 → 卸载 → 报告 → 还原"全流程。

---

## 阶段 4：功能完善与规则库

**目标**：提升"卸得干净"的能力与覆盖面。

- **内容**
  - 服务、计划任务、开机启动项清理；
  - 文件关联、右键菜单、COM 注册、Shell 扩展清理；
  - 占用文件"重启后删除"；
  - 内置软件指纹规则库（可增量更新）；
  - 批量卸载、卸载报告导出。
- **交付物**：功能完整版客户端 + 规则库文件。
- **验收标准**：覆盖更多软件类型；常见软件的残留项检出率明显提升。

---

## 阶段 5：测试、签名与发布

**目标**：打磨稳定性、通过安全软件与系统信任校验，正式对外交付。

- **内容**
  - 多版本 Windows（10 / 11）与多软件矩阵测试；
  - 高风险场景专项测试（系统组件保护、误删回滚）；
  - 代码签名（消除 SmartScreen 警告）+ 杀软误报申诉；
  - 打包、版本信息、更新机制（可选）。
- **交付物**：签名的正式发布版 + 用户手册 + 风险提示。
- **验收标准**：无高危误删缺陷；主流杀软无误报；用户可正常下载安装运行。

## 开发顺序原则（重要）

1. **只读优先**：先只扫描不删除，把识别准确率做扎实；
2. **安全先行**：备份/还原先于删除能力上线，否则不允许开启删除功能；
3. **分层解耦**：核心引擎与界面分离，界面方案可替换（详见技术选型文档）；
4. **小步验证**：每个阶段都以可运行、可验收的产物结束，不搞大爆炸式集成。
