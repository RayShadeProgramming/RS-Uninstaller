# RS-Uninstaller 技术选型与框架清单

> 文档版本：v0.3（技术路线调整为 Python）
> 日期：2026-10-17
> 说明：本文档确定技术方向、依赖与构建方式，不涉及具体编码细节。

---

## 1. 总体技术栈

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 语言 | **Python 3.10+** | 业务逻辑与界面统一使用 Python |
| 界面 | **tkinter + ttk** | Python 标准库自带，无第三方 UI 依赖 |
| 系统交互 | `winreg`、`ctypes`、`os`、`shutil` | 全部为标准库 |
| 目标平台 | Windows 10 / 11（64 位） | 仅 Windows |
| 运行时依赖 | **无** | 仅使用标准库，不安装任何第三方包 |
| 打包 | **PyInstaller**（后续执行） | `--onefile --windowed --uac-admin` 生成单个 exe |

---

## 2. 硬性约束

| 编号 | 约束 | 判定方式 |
| --- | --- | --- |
| C1 | 最终交付为一个 `.exe` | 交付目录中只有 exe |
| C2 | 目标机器无需安装 Python | 干净 Windows 上双击可运行 |
| C3 | 不使用 Qt 系 UI 框架 | 不引入 PySide6 / PyQt5/6 |
| C4 | 原生 Windows 外观 | ttk `vista` 主题 + 系统字体 |
| C5 | 桌面环境运行 | Windows 10 / 11 桌面 |

> 说明：PyInstaller 单文件模式会把 Python 解释器与标准库打包进 exe，运行时自解压到临时目录，因此**用户机器无需安装 Python**。

---

## 3. 界面方案选型

| 方案 | 第三方依赖 | 单文件打包 | 外观 | 结论 |
| --- | --- | --- | --- | --- |
| **tkinter + ttk** | 无（标准库） | ✅ 支持良好 | Windows 原生主题（vista） | ⭐ **首选** |
| PySide6 / PyQt6 | 有（Qt） | ⚠️ 体积大、需处理插件 | 原生近似 | ❌ 排除（明确不用 Qt） |
| wxPython | 有 | ⚠️ 打包复杂 | 原生 | 不推荐 |
| customtkinter | 有 | ✅ 可行 | 现代化自绘 | 备选（引入依赖） |
| pywebview | 有 + 依赖系统 WebView2 | ⚠️ 依赖系统组件 | Web | 不推荐 |

### 推荐结论

> **采用 tkinter + ttk，使用 `vista` 主题。**

理由：

1. **零第三方依赖**：标准库自带，连 `pip install` 都不需要；
2. **打包最省心**：PyInstaller 对 tkinter 支持成熟，单文件模式稳定；
3. **原生外观**：ttk 的 `vista` 主题在 Windows 10/11 上即为系统控件风格；
4. 界面以「列表 + 勾选 + 进度 + 对话框」为主，tkinter 完全覆盖。

**界面元素映射：**

| 界面元素 | 实现 |
| --- | --- |
| 软件列表 | `ttk.Treeview`（`show="headings"`） |
| 排序 | 点击表头切换升 / 降序 |
| 搜索 | `ttk.Entry` + `StringVar` 追踪 |
| 清理清单勾选 | 自定义 `CheckTreeview`（首列显示 ☑ / ☐） |
| 进度 | `ttk.Progressbar` |
| 确认 / 提示 | `tkinter.messagebox` |
| 状态栏 | `ttk.Label` |

## 4. 依赖清单（全部为标准库）

### 4.1 界面

| 模块 | 用途 |
| --- | --- |
| `tkinter` / `tkinter.ttk` | 窗口、控件、主题 |
| `tkinter.messagebox` | 确认与提示对话框 |

### 4.2 系统交互

| 模块 | 用途 |
| --- | --- |
| `winreg` | 注册表枚举、读取、递归删除 |
| `ctypes` | 系统还原点（srclient.dll）、服务管理（advapi32）、UAC 提权 |
| `os` / `os.path` / `shutil` | 文件遍历、移动、复制、删除 |
| `threading` / `queue` | 清理与还原的后台执行，避免界面卡死 |
| `json` | 注册表快照序列化 |
| `dataclasses` | 数据模型 |

> 刻意不引入：`pywin32`、`psutil`、任何 GUI 第三方库。

### 4.3 打包工具（仅开发环境）

| 工具 | 用途 |
| --- | --- |
| `pyinstaller` | 生成单文件、无控制台、带管理员清单的 exe |

## 5. 工程目录结构

```
RS-Uninstaller/
├── run.py                       # 启动入口
├── requirements.txt             # 运行时无依赖说明
├── build_exe.bat                # PyInstaller 打包脚本（后续使用）
├── README.md
├── 项目企划/
├── res/
│   └── icon.ico                 # 应用图标
├── rsu/
│   ├── __init__.py
│   ├── __main__.py              # python -m rsu
│   ├── app.py                   # 入口装配：权限、DPI、主题、主窗口
│   ├── models.py                # 数据模型
│   ├── util.py                  # 路径、格式化、日志、保护名单
│   ├── privileges.py            # 管理员检测与自我提权
│   ├── winreg_api.py            # 注册表封装
│   ├── win_svc.py               # 服务枚举与删除（ctypes）
│   ├── restore_point.py         # 系统还原点
│   ├── scanner.py               # 已安装软件扫描
│   ├── trace.py                 # 清理清单生成
│   ├── backup.py                # 注册表快照 / 隔离区 / 还原
│   ├── cleaner.py               # 清理执行
│   └── ui/
│       ├── __init__.py
│       ├── widgets.py           # CheckTreeview
│       ├── main_window.py       # 主窗口
│       ├── preview_window.py    # 清理预览
│       └── quarantine_window.py # 隔离区 / 还原
└── tools/
    └── gen_icon.py              # 图标生成脚本
```

**分层依赖方向（单向）：**

```
ui → app → 业务模块（scanner / trace / cleaner / backup）→ 系统封装（winreg_api / win_svc）
```

- `ui` 只负责展示与交互；
- 业务模块不导入任何 `tkinter`；
- 所有注册表与 Win32 调用集中在 `winreg_api` / `win_svc` / `restore_point`。

## 6. 构建与打包

### 6.1 开发运行

```bash
python run.py
```

### 6.2 打包为单文件 exe（待指示后执行）

```bat
pip install pyinstaller
build_exe.bat
```

等价命令：

```bat
pyinstaller --noconfirm --clean --onefile --windowed ^
  --uac-admin ^
  --name RS-Uninstaller ^
  --icon "res\icon.ico" ^
  --add-data "res\icon.ico;res" ^
  run.py
```

| 参数 | 作用 |
| --- | --- |
| `--onefile` | 生成单个 exe |
| `--windowed` | 不显示控制台窗口 |
| `--uac-admin` | 嵌入 `requireAdministrator` 清单 |
| `--add-data` | 打包图标资源（兼容 `sys._MEIPASS`） |

### 6.3 打包后校验

| 检查项 | 方法 | 通过标准 |
| --- | --- | --- |
| 单文件 | 查看 `dist/` | 只有 `RS-Uninstaller.exe` |
| 无 Python 环境 | 在未装 Python 的机器运行 | 正常启动 |
| 管理员权限 | 启动时 UAC 提示 | 出现提权提示 |
| 体积 | 文件属性 | 约 10~20 MB（正常） |
| 功能 | 手工走完整流程 | 扫描、预览、清理、还原均正常 |

> 说明：PyInstaller 单文件程序首次启动会解压到临时目录，启动略慢属于正常现象。

## 7. 风险与注意事项

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 被杀软误报 | 强制卸载 + 单文件打包容易被误判 | 代码签名、提交白名单 |
| 单文件启动慢 | 运行时自解压 | 可接受；必要时改用 `--onedir` 分发 |
| 注册表删除权限 | 部分系统键受保护 | 提权运行 + 失败项如实报告 |
| 文件被占用 | 程序运行中无法删除 | 记录失败项，提示关闭程序后重试 |
| 服务删除需重启 | 部分服务标记删除后需重启 | 在结果中提示 |
| tkinter 高 DPI | 缩放异常 | 启动时设置进程 DPI 感知并调整 `tk scaling` |

---

## 8. 技术选型小结

- **语言**：Python 3.10+，仅标准库。
- **界面**：tkinter + ttk（vista 主题），不使用 Qt。
- **系统交互**：`winreg` + `ctypes`，不引入 pywin32。
- **打包**：PyInstaller `--onefile --windowed --uac-admin`，目标机器无需 Python。
- **产物**：单个 `RS-Uninstaller.exe`，双击即用。
