## 4. 关键技术决策（已定）

| 编号 | 决策 | 结论 |
| --- | --- | --- |
| K1 | 开发语言 | **Python 3.10+**（已放弃 Go / C++） |
| K2 | 界面方案 | **tkinter + ttk（vista 主题）**，不使用 Qt |
| K3 | 依赖策略 | **仅标准库**，运行时不装任何第三方包 |
| K4 | 交付形态 | PyInstaller 单文件 exe，目标机无需 Python |
| K5 | 注册表操作 | `winreg` + 32 / 64 位视图 |
| K6 | 服务操作 | `ctypes` 调用 advapi32（SCM） |
| K7 | 备份格式 | 注册表 JSON 快照 + 文件隔离区 + journal |
| K8 | 执行模型 | 后台线程 + 队列，主线程只更新界面 |
