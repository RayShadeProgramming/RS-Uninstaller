## 4. 关键技术决策（已定）

| 编号 | 决策 | 结论 |
| --- | --- | --- |
| K1 | 开发语言 | **C++20**（不再使用 Go） |
| K2 | 界面方案 | **纯 Win32 API + 公共控件**，不使用 Qt |
| K3 | 交付形态 | **单个 `.exe`**，静态链接，无外部运行时 |
| K4 | 编译器 | 本地 MinGW-w64 g++ |
| K5 | 构建系统 | CMake + Ninja（备选 Makefile） |
| K6 | 数据库 | SQLite amalgamation（源码编译进 exe） |
| K7 | 架构分层 | `ui → app → core → platform`，core 不依赖 UI |
| K8 | API 策略 | 优先直接 Win32 API，**回避 WMI**，GUID 显式声明 |

## 5. 待确认事项（Open Questions）

| 编号 | 待确认事项 | 建议 / 备选 |
| --- | --- | --- |
| Q1 | 删除策略默认值 | 建议默认"移动到隔离区"，高级用户可开启"直接删除" |
| Q2 | 是否默认勾选创建还原点 | 建议**默认勾选**，作为安全底线 |
| Q3 | 是否保留控制台调试版 | 建议保留（阶段 0/1 用于快速验证），发布版不带 |
| Q4 | 规则库更新方式 | 建议先本地内置；联网更新作为可选项 |
| Q5 | 界面视觉风格 | 建议系统默认控件 + comctl32 v6；是否做深色主题待定 |
| Q6 | 是否引入 WTL | 建议不引入，纯 Win32 足够，减少兼容风险 |
| Q7 | 锁定 GCC 版本 | 建议在阶段 0 记录并固定，避免构建差异 |
| Q8 | 产品是否收费 / 是否开源 | 待定 |
