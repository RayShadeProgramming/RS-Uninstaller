# RS-Uninstaller

> 面向 Windows 客户端的「一步到位」深度强制卸载工具 —— 识别全机软件，**绕过官方卸载程序**，直接清理程序文件、用户数据与注册表残留。

- **产品定位**：Windows 专属 / 轻量绿色 / 深度清理
- **技术栈**：Go（核心引擎 + 图形界面，全链路无 CGO）
- **目标平台**：Windows 10 / 11（x64，兼容 x86 应用）
- **当前阶段**：📋 项目企划（**尚未进入代码开发**）

---

## 一句话说清楚它解决什么

现有的卸载工具有两个痛点：

1. **卸载要收费 / 弹广告**：点"卸载"跳出来的是软件自己的卸载程序，让你付费、看广告、填问卷。
2. **卸不干净**：卸载完还留下一堆 AppData、ProgramData、注册表项，越堆越多，持续污染系统。

RS-Uninstaller 的思路是：**不启动软件自带的卸载程序**，而是自己解析安装信息 → 构建"清理清单"（文件 + 注册表 + 服务 + 计划任务）→ 在安全兜底（还原点 / 备份）保护下一次性清除。

> ⚠️ 这是一类**高风险操作**。"强制卸载"的核心竞争力不是"删得狠"，而是**清理清单算得准 + 出事能还原**。所有设计都围绕这一点展开。
