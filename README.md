# RS-Uninstaller

> Windows 上真正「卸得干净」的卸载工具 —— 跳过软件自带的卸载程序，直接清理程序文件、用户数据与注册表残留。
>
> 当前版本：**v0.1.2**

---

## 为什么需要它

装软件容易，卸软件难。你可能遇到过这些情况：

- 点「卸载」，弹出来的却是软件自己的卸载程序：**要付费、看广告、填问卷**，甚至引导你再装一个别的软件；
- 好不容易卸完了，`AppData`、`ProgramData` 和注册表里还留着**一堆残留**，越积越多，拖慢系统；
- 有些软件卸载程序本身已经损坏，**根本卸不掉**，只能一直挂在系统里。

RS-Uninstaller 换了个思路：**不运行软件自带的卸载程序**，而是自己识别这个软件装在哪里、留下了什么，然后把这些内容一次性清理掉。

---

## 核心特性

**一键识别全机软件**
扫描本机所有已安装程序，包括 32 位与 64 位程序，显示名称、版本、厂商、占用空间和安装日期。

**跳过官方卸载程序**
不再被卸载时的付费墙、广告页、问卷拦截；卸载程序损坏、无法运行的软件也能处理。

**深度清理，不留尾巴**
程序目录、用户数据目录、注册表项与后台服务，一并纳入清理范围。

**清理前先看清单**
执行前完整列出「将要删除什么」，每一项都可以单独勾选或排除。看不明白的，可以先不删。

**默认彻底清理，可选保留备份**
默认直接永久删除，不额外占用磁盘空间；需要可恢复时，可在清理前勾选「保留备份到隔离区」，文件与注册表会先备份，随时能还原。

**单文件绿色版**
一个 `.exe`，下载即用，不需要安装，不依赖任何运行时或第三方组件。

## 工作原理

| 步骤 | 做什么 |
| --- | --- |
| 1. 识别 | 读取系统记录的安装信息，汇总成本机软件清单 |
| 2. 追踪 | 定位软件的安装目录、用户数据目录与关联的注册表项 |
| 3. 预览 | 生成清理清单，交给你确认或调整 |
| 4. 安全措施 | 创建系统还原点；如勾选「保留备份」，再导出注册表、把文件移入隔离区 |
| 5. 清理 | 永久删除（或移入隔离区），并输出一份卸载报告 |

整个过程由你主动发起、逐步确认，不会在后台偷偷改动系统。

## 使用方式

### 方式一：直接运行（推荐）

1. 下载 `RS-Uninstaller-0.1.2.exe`，放到任意目录（无需安装）；
2. 双击运行，在 UAC 提示中点「是」（清理系统级文件与注册表需要管理员权限）；
3. 在列表中找到要卸载的软件（支持搜索、排序；每次启动会自动重新扫描，也可按 F5 或点「刷新」手动更新），选中后点「卸载选中软件」；
4. 查看清理清单，确认无误后点「开始清理」（默认永久删除；需要可还原时勾选「保留备份到隔离区」）；
5. 完成后查看结果；如有问题，从「隔离区 / 还原」恢复。

### 方式二：从源码运行（开发者）

需要 Python 3.10+，Windows 官方安装包默认自带 tkinter，无需安装任何第三方依赖。

```bash
# 进入项目目录
cd RS-Uninstaller

# 启动（启动时会自动请求管理员权限）
python run.py

# 等价的模块方式
python -m rsu
```

打包为单文件 exe：

```bash
python -m pip install pyinstaller
build_exe.bat
```

或直接执行命令：

```bat
python -m PyInstaller --noconfirm --clean --onefile --windowed --uac-admin ^
  --name "RS-Uninstaller-0.1.2" ^
  --icon "res\icon.ico" ^
  --add-data "res\icon.ico;res" ^
  run.py
```

产物：`dist\RS-Uninstaller-0.1.2.exe`

## 安全与隐私

- **全程本地运行**：核心功能不联网，不收集、不上传你的软件清单、文件内容或任何使用数据。
- **默认彻底删除**：默认不保留隔离区备份，文件被永久删除；需要可回滚时，请在清理前勾选「保留备份到隔离区」。
- **系统还原点**：默认在清理前创建还原点（可在界面取消），用于回滚系统状态。
- **保护名单**：内置系统关键目录与共享组件保护，避免误删影响系统或其他软件。
- **操作可见**：所有删除项在执行前都会列出，不存在「静默清理」。

> ⚠️ 强制卸载属于系统变更操作，存在误删风险。请在执行前仔细确认清理清单，并保持默认的备份选项开启。

## 常见问题

**Q：它和 Geek Uninstaller 有什么区别？**
Geek 的做法是「先调用软件自带的卸载程序，成功后再扫描残留」。RS-Uninstaller 不调用官方卸载程序，因此可以绕过卸载时的收费与广告，也能处理卸载程序损坏的软件。

**Q：会不会误删别的软件的文件？**
清理清单基于安装目录、厂商信息、注册表关联等多重匹配生成，并有系统保护名单兜底。即便如此，仍建议你在执行前检查清单；默认会创建系统还原点，勾选「保留备份到隔离区」后还可从隔离区还原。

**Q：卸载后还能恢复吗？**
默认不能，文件是永久删除的，不会占用额外磁盘空间。如果希望可恢复，请在清理前勾选「保留备份到隔离区」；此外默认会创建系统还原点，可用于回滚系统状态。

**Q：隔离区占用空间怎么清理？**
打开「隔离区 / 还原」，点「清空隔离区」即可删除全部备份会话。注意：清空后这些备份无法再还原，且默认清理不产生备份，隔离区通常一直是空的。

**Q：为什么一定要管理员权限？**
清理 `Program Files`、`ProgramData` 以及 `HKLM` 下的注册表项需要管理员权限。没有权限时，这些位置无法彻底清理。

**Q：卸载后软件还显示在列表里怎么办？**
点击刷新即可。若仍存在，通常是该软件的注册表卸载项未被完全删除，可在清理清单中确认是否勾选了对应的注册表项。

**Q：支持卸载 Windows 自带应用 / 商店应用吗？**
暂不支持。当前版本只处理在注册表中登记卸载信息的桌面程序，商店应用（UWP）会在后续版本中加入。

**Q：卸载收费软件算破解吗？**
不算。本工具不修改软件、不绕过授权验证，只是替代软件自带的卸载流程，帮你把已安装的程序清理掉。
